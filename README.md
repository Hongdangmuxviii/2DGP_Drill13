# LEC15 게임 프레임워크 완성본

저장소 루트에서 실행:

```sh
python main.py
```

환경이 없다면 Python 가상환경을 만든 뒤 `requirements.txt`의 패키지를 설치한다. 그래픽 실행에는 SDL2가 필요하다. 이미지 경로는 소스 파일 기준이므로 다른 폴더에서 실행해도 된다.

## 화면과 조작

- 로고: 2초 후 타이틀로 전환. ESC 또는 창 닫기로 종료.
- 타이틀: Space로 새 게임 시작, ESC로 종료.
- 플레이: 좌우 방향키 이동, 1 작은 공 즉시 발사, 2 큰 공 즉시 발사, Space 마지막 종류로 발사, ESC 타이틀 복귀. 위쪽 숫자키와 넘버패드 모두 지원하며, I를 먼저 누를 필요 없다.
- 5초 동안 가만히 있으면 잠든다. Space 한 번으로 일어나 공을 발사하거나 방향키로 움직인다.
- I: 캐릭터가 누운 채로 멈추고 아이템 화면을 연다. 0은 공 해제 후 일어나서 복귀, 1은 작은 공 즉시 발사, 2는 큰 공 즉시 발사 후 복귀. ESC는 변경 없이 복귀.
- 아이템 선택 후에는 서 있는 상태로 복귀하고 수면 대기 시간을 다시 시작한다. 1/2를 누르는 즉시 해당 공을 발사한다. Space는 마지막 종류로 추가 발사하는 키다.
- 아이템 화면에서는 월드 업데이트가 멈추며, 복귀하면 같은 캐릭터와 공들이 유지된다.

아이템 진입 키 I와 선택 후 즉시 복귀, 0의 공 장착 해제 동작은 강의 이미지에서 세부 규칙을 명시하지 않아 정한 구현 규칙이다.

## 구조

`main.py`는 캔버스와 프레임워크 실행만 담당한다. 각 모드는 init, finish, handle_events, update, render, pause, resume의 7개 함수를 제공한다. 슬라이드에서 혼용하는 draw/render는 render로 통일했다.

`change_mode`는 현재 모드를 종료하고 새 모드를 초기화한다. `push_mode`는 기존 모드를 일시정지하고 위에 새 모드를 얹는다. `pop_mode`는 맨 위 모드를 종료하고 기존 모드를 재개한다. 마지막 모드까지 제거하면 실행을 종료한다.

플레이 종료 시 월드를 비우고, 아이템 모드 종료 시에는 월드를 유지한다. 모드 변경이나 종료 직후 이전 모드의 업데이트/렌더링을 실행하지 않는다. 기존 add_oject 오타는 add_object로 수정하고 이전 호출용 별칭을 유지했다.

## 검증

```sh
python tests/check_modes.py
python tests/check_sdl_input.py
```

화면 입출력을 대체하여 실제 모드, 캐릭터, 월드의 동작을 검사한다. 실제 그래픽 창의 시각 검증과는 별개다.

## 처음 설치

Python 3.9 이상에서 다음을 실행한다.

```sh
python -m venv .venv
# macOS/Linux
source .venv/bin/activate
# Windows는 .venv\Scripts\activate
python -m pip install -r requirements.txt
python main.py
```
